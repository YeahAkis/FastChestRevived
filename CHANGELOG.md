# Changelog

## 2.0

- Rewritten from scratch
- Now on Fabric, Forge and NeoForge, from 1.16 all the way up to 26.3
- The client doesn't create block entities for chests anymore, so no renderer and no ticker running for each chest
- Copper chests are supported
- Breaking cracks show up on chests again
- Removed the config and Mod Menu screen, if you don't want static chests just remove the mod
- Doesn't overwrite vanilla chest model files anymore, so it plays nicer with resource packs
